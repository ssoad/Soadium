# Soadium OS

**Soadium OS** is a custom configuration suite for Ubuntu run on GNOME. It transforms a standard Ubuntu installation into a personalized, premium experience.

## Features
- **Custom Theme**: A tailored GTK and Shell theme.
- **Icon Pack**: Distinctive and modern iconography.
- **Shell Experience**: Zsh with a custom prompt (Starship) and useful aliases.
- **Extensions**: A curated list of GNOME extensions for productivity.

## Usage
To install Soadium OS on your Ubuntu machine:

1. Clone this repository.
2. Run the installer:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```

## Directory Structure
- `install.sh`: Main installation script.
- `scripts/`: Modular setup scripts.
- `assets/`: Themes, icons, and wallpapers.
- `configs/`: Configuration files (dotfiles).

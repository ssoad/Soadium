# Soadium OS — Brand Palette

The identity plays on **Soadium = ssoad + sodium (Na, element 11)**.
The logo is an "S" drawn as an electron orbit inside a hexagonal crystal
badge; the yellow electron is the color sodium burns in a flame test.

| Token | Hex | Usage |
|---|---|---|
| Deep Space   | `#0B1021` | Backgrounds, terminal, badge fill |
| Abyss        | `#060913` | Wallpaper gradient floor |
| Iris         | `#6366F1` | Primary brand / gradients start |
| Iris Light   | `#818CF8` / `#A5B4FC` | Prompt accents, wordmark fade |
| Electron Cyan| `#22D3EE` | Gradients end, success, links |
| Sodium Flame | `#FACC15` | THE accent — electron, highlights, CTA |
| Slate Text   | `#E2E8F0` | Primary text on dark |
| Muted        | `#64748B` | Secondary text |
| Orbit Line   | `#3B4368` | Hairlines, borders |
| Error        | `#F87171` | Errors only |

Rules of thumb:
- Dark-first. Deep Space is the canvas everywhere (shell, terminal, installer).
- Iris→Cyan gradient for structure (frames, strokes, headers).
- Sodium Flame is scarce: one glowing accent per surface, never large fills.
